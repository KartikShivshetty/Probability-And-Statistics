# Experiment 02 — Statistical Analysis using E-Commerce Dataset

## Objective / Scope

This experiment involved importing and analyzing an E-Commerce dataset using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn.

Descriptive statistics including mean, shape, unique values, and distribution analysis were performed. Histogram plots and graphical visualization techniques were also implemented.
